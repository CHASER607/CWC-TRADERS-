# CWC-TRADERS- (Pro App Concept)

Professional trading portal + mobile app concept for:
- EA Merge strategy workflows
- RoboTrader automation control
- Take-Profit Signals integration direction (`take-profit-signals.co.za`)
- Broker server connectivity for live execution routing

## Pro capabilities showcased
- Broker server gateway architecture (routing, failover, acknowledgements)
- Mobile execution dashboard with account sync and risk controls
- Infrastructure metrics (latency, uptime, monitoring, encryption)
- Security and compliance blocks (vaulting, audit trails, RBAC/2FA)

## Run locally

```bash
python3 -m http.server 4173
```

Open: `http://localhost:4173`
